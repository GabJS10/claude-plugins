# gabjs-plugins

Marketplace de plugins para Claude Code by GabJS10.

## Añadir el marketplace

```
/plugin marketplace add <ruta>
```

Sustituye `<ruta>` por la ruta local o el repositorio de este marketplace.

## Plugins

| Plugin | Descripción |
| --- | --- |
| [usage-bar](plugins/usage-bar/README.md) | Status line minimalista con el uso de las ventanas de 5h y semanal de tu suscripción, con tiempo hasta el reinicio. |
